# 澄境筆記 ChengJing Notes v0.7.5

<p align="center"><img src="build/icon-1024.png" width="128" alt="澄境筆記圖示"></p>

澄境是一款繁體中文、本機優先的視覺筆記與 AI 研究桌面應用。它最大的特色在於「第二大腦」，可以將日常的喃喃自語、會議記錄、白板規劃等一切資訊化為神經元，透過 AI 判斷神經元之間的聯繫，發現連你本人可能都從未發現的潛意識狀態。

> 本機優先、無邊框的視覺筆記與第二大腦。支援 OpenRouter、Gemma 4，以及繁體中文、簡體中文、英文、日文與韓文介面。

## 直接安裝

目前正式安裝包支援 Apple Silicon Mac，以及 Windows ARM64／Intel、AMD x64：

- [Windows ARM64 安裝程式](https://github.com/Coyoter/chengjing-notes/releases/download/v0.7.5/ChengJing-0.7.5-arm64-Installer.exe)

- [Windows Intel／AMD x64 安裝程式](https://github.com/Coyoter/chengjing-notes/releases/download/v0.7.5/ChengJing-0.7.5-x64-Installer.exe)
  - SHA-256：`030830b0c185f45455fceb41744c44f8361c7a47c7a848e1267e73ee2c0b4cf2`
- [Apple Silicon Mac DMG](https://github.com/Coyoter/chengjing-notes/releases/download/v0.7.5/ChengJing-0.7.5-arm64.dmg)
  - SHA-256：`ae1257b4c8e4d8d8f4f069f56744d957f6655500f96b708c63a7513ee29f9a2e`

Windows ARM 電腦請下載 ARM64；一般 Intel／AMD 電腦請下載 x64。目前尚未使用商業 Windows 程式碼簽章憑證，因此 SmartScreen 可能顯示「未知的發行者」，啟用 Smart App Control 的電腦也可能直接封鎖安裝檔。請先用 Release 隨附的 SHA-256 核對檔案；不要為了安裝而降低主要工作電腦的安全設定。

開啟 DMG 後，把「澄境」拖進「應用程式」。目前是 ad-hoc 簽章版本，尚未使用 Apple Developer ID 公證；若 macOS 阻擋，請先嘗試開啟一次，再到「系統設定 → 隱私權與安全性」向下捲動，按「強制打開（Open Anyway）」，並在再次出現警告時確認「打開」。

## v0.5.9 跨節點更新一致性

- 修正某些 Mac 顯示「目前 0.5.7、GitHub 最新 0.5.3」且無法更新的問題。GitHub 實際最新版沒有倒退；原因是 Cloudflare Cache API 由各資料中心獨立保存，個別節點可能仍握有舊索引。
- Worker 現在先讀取全球 KV 的最後可靠版本，並把該版本加入資料中心內部快取鍵；KV 從 0.5.8 升到 0.5.9 時，所有舊世代快取會自然失效，不必逐節點清除。
- 即使讀到舊快取，Worker 也會比較 KV 與快取版本並選擇較新者，再回填目前節點；不再無條件優先採用 24 小時 stale cache。
- 每個 GitHub Release 額外附上小型 `.dmg.sha256` 資產。GitHub API 限流時，Atom Feed 備援仍能驗證 DMG，不必退回舊快取。
- App 遇到比自身版本更舊的來源時會視為過期並繼續嘗試下一個來源；所有來源都過期時顯示清楚說明，不再把舊版本標成「GitHub 最新版」。
- 更新檢查失敗會清除畫面上的舊版本資訊，避免同時顯示過期數字與錯誤訊息。
- 以未修改的 0.5.7 安裝包強制走備援路徑驗收，已成功取得 0.5.8 的 DMG、下載網址與 SHA-256。

## v0.5.8 本機第二大腦安全模式

- 修正本機 Gemma 執行「AI 整理連結」時，超大型提示與 6,000-token 輸出配置可能讓 ONNX Runtime 出現 `SafeIntOnOverflow / Integer overflow`，進而造成介面長時間卡住的問題。
- 本機模式保留第二大腦能力，但改為安全範圍：每次挑選最近與重要的 18 個神經元、24 組候選關係、12 條既有連線，最多建立 8 條新關係；完整全腦分析仍建議 OpenRouter。
- 本機連結輸出上限降為 768 token；所有本機功能的底層硬上限為 1,024 token，即使上層誤傳 6,000 也不會照單執行。
- 本機 JSON 不完整時不再自動重跑同一份大型任務；連結完成後也不會立刻接著生成今日反思，避免連續兩次高負載。今日反思仍可由使用者單獨生成，並使用 18 個神經元與 384-token 安全範圍。
- 所有本機推論改為單列排隊，避免兩個 ONNX `OrtRun` 同時進入同一個模型工作階段；超過 60 秒會透過 Transformers.js 中止條件停止。
- 過長輸入、ORT 容量溢位與逾時都改顯示五語友善說明，不再把底層英文錯誤堆疊直接丟給使用者。
- OpenRouter 保留原本 84 個神經元、120 組候選、最多 30 條連線、JSON 自動修復與連結後反思更新的完整模式。

## AI 設定

### OpenRouter

1. 打開「設定」。
2. 選擇 OpenRouter。
3. 輸入自己的 API 金鑰並按「儲存金鑰」。
4. 選擇精選模型、同步最新模型，或手動輸入 `供應商/模型名稱`。

金鑰不會存進一般設定、筆記資料庫或備份，而是以 AES-256-GCM 加密保存於這台 Mac 的澄境資料目錄；主密鑰與密文檔案權限均為 0600。這個方式不會使用 macOS 鑰匙圈，因此不會反覆要求鑰匙圈權限。

由於不使用鑰匙圈、使用者密碼或硬體安全區，若他人已能完整讀取你的 macOS 帳號檔案，這種本機加密無法提供與鑰匙圈相同的防護；它的用途是避免明碼曝露與一般誤讀。

### Gemma 4 E2B

1. 打開「設定」。
2. 選擇 Gemma 4 E2B。
3. 按「下載模型」。

模型約 2.9–3.2 GB，第一次下載完成後可離線使用。生成時文字不會傳給 OpenRouter 或 Google。
