## 本機驗證

- 353 個前端單元測試、114 個 Electron Node 測試通過；TypeScript 與正式建置通過。
- 54 組版面與主題情境，測得的遮擋、水平溢出、反思按鈕裁切及主題不同步失敗數為 0。
- 看板及待辦階層實際 UI 回歸通過，含本次新增的資料保存與詳情面板案例。
- 一萬張合成卡片的背景工作集合約 228ms，畫面上限維持 200 顆，歷史內容仍可搜尋。這是限量工作集合測試，不是完整一萬張 AI 分析時間。
- 真正 Electron 的正式檔案協定可由背景執行緒讀取本機資料庫。
- 所有資料與退出驗證使用隔離環境、合成資料或模擬服務，未改動使用者資料或真實 Google Drive。

各平台安裝包另由 GitHub Actions 使用同一 commit 建置、檢查架構、版本與簽章；不把封裝檢查宣稱為所有實體裝置皆已測試。
