# 澄境筆記 0.10.10

## 修正卡片庫標籤色點

- 修正「卡片庫 → 依標籤」部分色點錯誤顯示灰色的問題。色點現在與隻言片語、標籤選擇器及其他共用標籤介面使用相同的色彩變數。
- 移除卡片庫自建的重複配色表，直接沿用 jade、sky、violet、rose、amber、slate 共用配色；原本設定為灰色的 slate 標籤仍保留灰色。
- 明亮、深色與墨色主題會同步更新色點；選取、滑鼠停留、鍵盤焦點及行動版分類抽屜不改變標籤所屬顏色。未知舊色碼的預設值亦與共用標籤選擇器一致。

## 資料與相容性

本次只修正顯示樣式，不重設標籤色彩、不修改標籤 ID、卡片內容或標籤關聯，也不更動封存、同步與備份格式。更新後無需重新建立標籤。

## 回歸檢查

新增瀏覽器實際計算色彩的比對測試，涵蓋桌面與行動版面、三種主題、全部六種既有色彩及未知舊色碼預設值，同時檢查標籤篩選、選取／停留／焦點、重新載入及資料不變性。正式發布工作流程會執行此測試以及既有型別、前端、Electron、版面溢出、封存／卡片庫與隻言片語卡片整合測試；結果以 GitHub Actions 紀錄為準。

## 安裝包範圍

本次正式版提供 macOS Apple Silicon／ARM64 DMG 與 SHA-256 校驗檔。共用前端修正亦適用於 Android 介面，但本次不另行產出 APK、Windows 安裝包，也不更新 Google Play。行動版面測試使用 Chromium 模擬，並非 Android 實機驗證。
