# 澄境筆記 0.10.8 — 封存一致性與卡片庫整合

## 封存不再留在工作區

修正看板右鍵「移到封存」後卡片仍留在畫面的問題。封存卡片改為僅能由卡片庫的「封存」開啟；今日、白板、全域搜尋、第二大腦、關聯待辦與劃記同步隱藏，相關計數也會更新。日誌不會重新開啟已封存的原文。

封存不是刪除：卡片內容、標籤、自訂屬性、看板位置、白板位置與關聯資料均保留。還原後原有位置、待辦與劃記會重新出現。備份與同步仍保留封存資料；已另存的歷史 AI 對話或報告不會被改寫。

## 一個卡片庫，四種檢視

移除桌面與 Android 的獨立「資料庫」導覽入口，將全域標籤管理整合到卡片庫。可新增、重新命名、刪除及篩選標籤，並與領域、主題、置頂、卡片類型及文字搜尋共同使用。

卡片庫保留原本的格狀、列表與網址收藏，新增表格及階段視圖。原資料庫的階段編輯、關聯待辦／完成狀態／期限、批次選取、移至垃圾桶、確認後永久刪除與分頁功能均收進卡片庫。非預設的自訂階段也會顯示，不會因為改版消失。

本次不搬移或重建資料表，不清除自訂欄位、分類或標籤；舊的資料庫導覽識別會導向卡片庫。

## 發布範圍

此儲存庫的自動發布流程產生 macOS Apple Silicon DMG 與 SHA-256。共用介面的修正同時包含 Android 原始碼，但本次 GitHub Release 不宣稱已發布 Android APK 或 Google Play 更新。
