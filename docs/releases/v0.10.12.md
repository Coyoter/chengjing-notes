# 澄境筆記 0.10.12

## 標籤文字與底色一起延伸

- 修正 Android 隻言片語的標籤及「＋標籤」被固定寬度按鈕樣式壓縮、文字反覆換行的問題。更多操作按鈕的樣式現在只作用於時間列，不再影響標籤或標籤選單。
- 標籤底色隨名稱自然加寬；名稱保持單行，超過可用寬度時以省略號顯示。顏色色點與移除圖示保留在同一列，完整名稱及實際儲存內容不會被截短。
- 多個標籤可整顆換到下一列，不會把單一標籤的文字拆成直排。共用標籤元件涵蓋片語草稿、已儲存片語、卡片編輯器與選單；白板維持原有精簡工具列。
- 保留 0.10.11 的整合卡片庫、片語卡片化、封存規則、共用標籤色彩與原生同步功能，不變更資料格式或既有標籤關聯。

## 回歸驗證

新增實際瀏覽器幾何檢查，涵蓋手機／桌面寬度、三種主題、放大字體、五種語言、長中文與無空格英文標籤、草稿及已儲存標籤、加入／移除、重新載入及卡片庫篩選。正式發布流程保留既有回歸測試與五件安裝產物的同版本、同來源提交及雜湊驗證；結果以 GitHub Actions 紀錄為準。手機介面測試使用 Chromium 模擬，不等同 Android 實機操作驗證。

## 全平台安裝檔

提供 macOS Apple Silicon DMG、Windows x64／ARM64 EXE、沿用原簽章的 Android APK 與 Google Play AAB，並附 SHA256SUMS 及 release-manifest.json。Android versionName 為 0.10.12、versionCode 為 16。所有安裝檔重新建置，不使用舊版改名。本次上傳 GitHub Release，不自動提交 Google Play。
