# 澄境筆記 0.10.19

即使 macOS 的選單列沒有正常收起，全螢幕頂部也應保持可用。

- 前一版只恢復遺失的自動隱藏呈現狀態。本次加入獨立的內容保護：讀取實際可見的系統選單列視窗範圍，讓澄境的名稱、搜尋、操作區與拖曳區位於遮擋下方。
- 自動隱藏旗標正確但選單列仍覆蓋畫面時，也能保護內容；不必依賴 macOS 先把選單列藏起來。
- 選單列消失後恢復原本配置，沒有永久頂部留白。高度由系統實際幾何計算，支援負座標、不同螢幕倍率與應用縮放。
- 視窗大小、位置、所在螢幕與原生全螢幕保持不變。不修改 macOS 選單列偏好、筆記或同步資料。
- 在返回應用、顯示器喚醒、選單操作及滑鼠返回內容等事件後檢查；只在內容配置需要改變時更新。不定時反覆重設視窗。

## 驗證與限制

已確認實際安裝版本為 0.10.18，出錯視窗仍是原生全螢幕。原生對照測試在自動隱藏旗標仍正確時，建立真正的頂部遮擋視窗：舊版的名稱與搜尋區仍位於遮擋內，新版會依量測高度保護內容。移除遮擋後回到零位移，並驗證縮放補償與視窗外框不變。

這是針對實際遮擋的內容保護，並不是宣稱已找到 macOS 偶發選單列異常的全部根因。原生量測不讀取其他視窗標題、筆記文字或畫面影像。

## English

Full-screen controls remain usable even if macOS leaves the menu bar visible.

- v0.10.18 repaired lost presentation flags. This release adds independent content protection based on the actual visible menu-bar bounds, placing the brand, search, actions and drag area below the obstruction.
- Protection also works when auto-hide flags remain correct but the menu bar still covers the window. The original layout returns when the obstruction disappears, without a permanent blank strip.
- Insets use measured DIP geometry and compensate for application zoom, including negative display origins and mixed display scales.
- Native full screen, window geometry and system preferences remain unchanged. Checks follow activation, display wake, menu tracking and pointer return; the app does not periodically reset its window.
- Native regression testing uses a real top overlay while auto-hide flags remain healthy. The old version leaves controls underneath it; the new version protects them, removes the inset afterward and retains the window bounds. This validates resilience to obstruction, not every underlying macOS trigger. No other window titles, note text or screen images are read by the measurement code.
