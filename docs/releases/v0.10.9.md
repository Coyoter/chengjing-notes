# 澄境筆記 0.10.9：隻言片語就是卡片

## 不必再轉換，標籤立即相通

在隻言片語、桌面全域快速記錄或 Android 快速記錄輸入的內容，現在第一筆寫入就是卡片，初始狀態為「待整理」。它立即出現在卡片庫，也能透過原有標籤、搜尋、表格與階段看板找到。標籤及釘選不會讓它離開待整理區。

隻言片語不再是一套獨立內容庫，而是待整理卡片的入口。雙擊會開啟同一張卡片的完整編輯器，保留格式及版本歷史；不會再用純文字浮層覆寫已編輯的豐富內容。

## 整理是放置與連結，不是複製

- 右鍵「整理到…」可選既有主題、白板，或看板與列表。仍使用原卡片 ID，標籤、全文、建立時間及其他屬性不變。
- 「新增為待辦」建立連結原卡片的未排期待辦；重複加入同一個尚未完成、未排期且標題相同的待辦，不再產生另一筆。
- 整理完成會離開隻言片語區，但保留在卡片庫。也可選「完成整理（保留於卡片庫）」而不指定主題。主題與白板／看板不是互斥類型，同一張卡片可放在不同工作情境中。
- 封存與垃圾桶沿用卡片規則，不再直接永久刪除片語。封存內容只在封存入口取用，不會因整理或同步重新出現在一般前臺。

## 舊資料及整合入口

啟動時以交易搬移既有片語，保留原始 ID、全文、標籤、釘選及時間；第二大腦雙端連線、已有共享對照與待辦來源同步改指同一張卡片。遇到意外 ID 衝突會使用安全的對照 ID，不覆寫其他卡片。搬移失敗會整筆回滾，不會先刪掉半批舊資料。

舊格式備份與 Google 同步封包仍可讀取，不更改同步協定或刪除舊表結構；重複收到資料不會再生一張卡片。已整理或封存內容若收到舊裝置的不同編輯，差異保留在卡片版本歷史，不會直接覆寫目前內容或解除封存。所有常用裝置請一併升級，避免舊版仍把片語與卡片當成不同內容。

Android 分享接收、AI 動作與 MCP 的片語建立入口也改用卡片；MCP 舊 fragment 入口仍相容。共享紀錄只遷移本機對照，不會自動分享新的內容，也不會主動重發或撤回公開副本。

## 介面與驗證

繁體中文、簡體中文、英文、日文、韓文的隻言片語說明已改成待整理卡片，不再提示「轉成卡片或刪除」。Android 快速記錄補上標籤選擇器，桌面和手機都具備防重複送出及失敗保留草稿。

新增 `src/lib/fleetingCards.test.ts` 與 `npm run qa:fleeting-cards`，驗證標籤查找、同 ID 放置、待辦連結、搬移回滾、舊同步重播、版本復原、封存及桌面／手機操作。正式發布工作流程會先執行型別檢查、單元測試、既有版面與封存回歸，以及本次新增操作測試，再建立安裝檔。

## 本次安裝包

本次正式版提供 **macOS Apple Silicon／ARM64 DMG** 及 SHA-256 校驗檔。Android 共用前端原始碼已更新，但本次不另外建置 APK、Windows 安裝檔，也不代表 Google Play 已更新。維持原有簽章方式與發布範圍。
