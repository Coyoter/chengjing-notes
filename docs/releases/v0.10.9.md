# 澄境筆記 0.10.9

## 隻言片語，從第一刻就是卡片

- 快速記錄直接建立未整理卡片，立即出現在卡片庫、標籤、搜尋及第二大腦，不再需要「轉成卡片」。
- 隻言片語是快速收件入口；新增標籤或釘選不會把內容移出此處。歸入主題、加入待辦／白板／看板，或選擇「完成整理」後，內容仍留在卡片庫。
- 右鍵提供目的地選擇，能選擇既有或新增白板／看板及看板列表。使用同一張卡片與原有標籤，不會為每個目的地另外複製內容。加入待辦會建立連回原卡片的待辦項目。
- 雙擊直接開啟原卡片；編輯與標籤共用同一份資料。封存與垃圾桶沿用 0.10.8 的可見性規則。
- 桌面主畫面、選單列快速記錄、Android 共用介面及分享入口、AI 動作與 MCP 的片語建立操作均改用卡片；舊 MCP fragment 參數保留相容別名，搜尋與神經元不會重複計算。
- 更新繁中、簡中、英文、日文、韓文操作說明，移除隻言片語需先轉成卡片的描述。

## 現有資料與相容性

- 初次開啟會自動搬移舊片語，保留文字、標籤、釘選及原始時間，並重新連結第二大腦關係、共享紀錄及既有片語待辦。一般情況沿用原 ID；遇到與既有卡片撞號則安全保留兩者。
- 搬移可重複執行，整批具交易保護。較新的卡片不會被舊備份或舊裝置片語覆寫；不同的舊內容與標籤／釘選保留在版本紀錄中。
- 備份匯入採完整交易後搬移；新備份仍沿用原備份格式，包含未整理狀態。正式備份與歷史報告不會因介面合併而刪除。
- 舊版本曾經手動「轉成卡片」產生的副本沒有可靠來源識別，因此不自動刪除或猜測合併。為避免舊版與新版對片語的理解不同，建議同步裝置都更新到支援此模型的版本；尚未更新的裝置可能只會在卡片庫顯示新版片語。

## 發布範圍

本次正式版安裝檔為 macOS Apple Silicon／ARM64 DMG，附 SHA-256。共用前端修改包含 Android 介面，但本次不另行產出 APK、Windows 安裝包，也不更新 Google Play。

## 回歸驗證

發布工作流程執行 TypeScript 型別檢查、完整前端／Electron 測試、版面溢出檢查、封存／卡片庫操作測試，以及新增的隻言片語卡片整合操作測試。實際結果以此標籤對應的 GitHub Actions 紀錄為準。
