# 澄境筆記 0.10.16

讓左側選單只留下你常用的功能。

## 桌面選單自訂

- 在左側主要功能上按右鍵，選擇「隱藏此功能」。隱藏白板時，「最近白板」也會一起收起。
- 在左側選單空白處按右鍵，即可在「顯示隱藏功能」中逐項找回，或一次全部顯示。
- 隱藏只影響這台裝置的選單，不會刪除筆記、白板、看板或其他資料，也不會打斷目前開啟的工作。
- 重新開啟應用仍會保留隱藏設定；重新顯示時保留原本順序。拖曳排序、Alt＋方向鍵、收合側欄與五種語言皆可搭配使用。
- 設定與底部工具保留可用；即使主要項目全部隱藏，仍可從空白處找回。鍵盤可聚焦選單後按 Shift＋F10，使用方向鍵選擇、Enter 執行、Escape 關閉。

本次功能適用 macOS 與 Windows 左側選單；Android 導覽方式維持不變。各平台安裝包由同一版本原始碼建置。

## English

Keep only the features you use in the desktop sidebar.

- Right-click a primary navigation item and choose **Hide this feature**. Hiding Whiteboards also hides the recent-whiteboards section.
- Right-click empty sidebar space to **Show hidden features**, individually or all at once.
- This is a per-device display preference: notes, whiteboards, kanban boards and other data remain untouched, and your current workspace stays open.
- Hidden items stay hidden after restart and return in their saved order when restored. Drag reordering, Alt + arrow keys, collapsed navigation and all five interface languages remain supported.
- Settings and footer tools stay available, even if every primary item is hidden. Keyboard users can focus the sidebar or a navigation item, press Shift + F10, then use arrow keys, Enter and Escape.

The feature applies to the macOS and Windows sidebar. Android navigation is unchanged. All platform packages are built from the same versioned source.
