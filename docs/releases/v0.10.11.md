# 澄境筆記 0.10.11

## 全平台使用同一套最新版結構

- 卡片庫整合原資料庫的標籤、表格、階段看板及批次操作入口。
- 隻言片語從建立時就是同一卡片；標籤、搜尋、分類與整理流程共用內容。
- 卡片庫標籤色點沿用共用配色，與隻言片語及標籤選擇器一致。
- 發布來源必須整合上一個完整跨平台版的修正，不能因改用新建置流程而退回舊 Android 原生功能。

## 下載產物

macOS Apple Silicon DMG、Windows x64/ARM64 EXE、Android direct APK 與 Google Play AAB 全部取自同一個來源提交；提供 SHA256SUMS 與 release-manifest.json。正式公開前必須驗證所有產物均已完整上傳。

Android versionCode 為 15。GitHub APK 必須沿用既有正式簽章；Play 安裝來源可能使用不同簽章，不應為了安裝 APK 而直接解除安裝、遺失本機資料。AAB 是 Play 上架用套件，不是可直接安裝的 APK。上傳 AAB 到 GitHub 不代表已提交或更新 Google Play。

自動測試及封裝檢查不等同所有 Windows／Android 真機情境均已驗證。此說明存在於原始碼或草稿中，不代表 Release 已完成；以實際 Actions 結果與公開安裝檔為準。
