# 澄境筆記 0.10.22

## 循環待辦完整支援

### 原有待辦也能設定循環
透過待辦的「編輯」視窗，可以替既有任務設定或取消循環，並在原本的編輯對話框中一併管理標題、期限與重複週期；從筆記建立的待辦與子待辦也能使用循環設定。無須刪除既有任務重新建立。

### 讓介面回到澄境原本的設計語言
新增待辦只留下輕巧的循環按鈕，按下後展開沿用澄境配色、圓角與間距的設定面板。可選每天、每週指定星期、每月 1–31 日；既有待辦的編輯視窗則以同一組控制元件顯示，適用亮色、深色與墨色主題。

### 不完成上一期，也不會擋住下一期
循環日期推進不再依賴勾選完成：進入待辦頁面、或跨越新的本地日期時，會依日期補上到期的循環項目，原本尚未完成的任務仍會保留。重複建立以穩定的週期識別避免重複；完成當期仍可排出下一期。對於短月份，29–31 日規則使用當月最後一天，之後恢復指定日期。既有任務開啟循環時，保留逾期工作，不強迫清除歷史。

## 跨平台版本

本版修正共用待辦操作介面，適用 macOS、Windows 與 Android；Android versionCode 為 26。桌面版更新仍透過 GitHub Releases / Cloudflare 更新索引；使用者資料保留在原有本機或既有 Google Drive 備份機制。Android 安裝包發布不代表 Google Play 上架。
