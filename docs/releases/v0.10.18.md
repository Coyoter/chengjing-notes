# 澄境筆記 0.10.18

補上 macOS 原生全螢幕的選單列狀態恢復。

- 0.10.17 處理一般視窗的位置；本次另行處理「視窗仍是全螢幕，但 macOS 的自動隱藏呈現狀態遺失」的情況。
- 進入全螢幕時保留 macOS 建立的正常呈現狀態。返回應用、喚醒顯示器等事件後，只有仍在前景的全螢幕視窗遺失該狀態時，才恢復它。
- 單獨關閉／喚醒顯示器與電腦睡眠、登入解鎖是不同事件，現在直接接收顯示器喚醒通知。
- 不以退出再進入全螢幕、填滿、移動視窗或增加頂部空白處理；視窗大小、所在螢幕與原生全螢幕保持不變。
- 尊重系統選單列偏好。偏好改變時停用舊基準；滑鼠移到上方正常顯示選單時不介入，也不修改其他應用的呈現狀態。
- 原有「顯示 → 記錄視窗位置診斷」會補記全螢幕呈現旗標與修復事件，仍不記錄筆記內容。

## 已確認與驗證範圍

原生量測觀察到：全螢幕視窗返回時，視窗旗標與全螢幕外框仍存在，但應用的原生呈現旗標可能短暫回到一般模式。這說明只檢查座標或 isFullScreen 不足以確認選單列行為。

故障注入驗證使用真正的原生全螢幕視窗，刻意清除呈現狀態：0.10.17 不會自行恢復自動隱藏，新版會恢復正常基準，外框與全螢幕旗標不變。另已測試隱藏／返回、閒置返回、實際關閉顯示器後喚醒，以及退出全螢幕恢復一般選單列。測試使用隔離資料。

這證實狀態遺失的修復機制與上述回歸情境；尚未完整還原每一種長時間偶發的自然觸發條件，不能把故障注入當成已證實所有根因。

## English

This release adds macOS native full-screen menu presentation recovery.

- v0.10.17 addressed ordinary window geometry. This release separately handles a native full-screen window whose application presentation state has lost auto-hiding.
- The app remembers the OS-established presentation state on full-screen entry and restores it only for the active full-screen key window when that state is missing.
- Display-only wake is observed directly, independently of system resume or authentication unlock.
- Recovery does not exit/re-enter full screen, fill, reposition or pad the window. Geometry and the native full-screen state remain unchanged.
- Changed system preferences invalidate the old baseline. Normal menu reveal and other applications are left alone. Optional diagnostics include presentation flags and recovery events, never note text.

Native measurements observed transient presentation-state loss during a full-screen return. Fault injection in a real full-screen window demonstrates that v0.10.17 leaves the lost auto-hide state unresolved, while this version restores it without changing geometry. Isolated testing also covers hide/return, idle return, actual display sleep/wake and ordinary menu restoration after full-screen exit. These checks validate recovery behavior, not every natural long-duration trigger or every possible root cause.
